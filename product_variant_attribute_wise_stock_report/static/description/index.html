Schedule Activity Dashboard Schedule Activity Dashboard

This provides a centralized dashboard to view all scheduled tasks. From this dashboard, you can efficiently manage activities by updating their status, editing details, viewing information, or deleting entries.

Video Tutorial
Explore this module
User Role Configuration :
  1. Navigate to Settings > Users & Companies > Users
  2. Open the specific User Profile you want to configure
  3. Scroll to the Access Rights tab
  4. Locate the Schedule Activity Dashboard settings to define their role:
    • Activity Supervisor : Can access their own activities, as well as the activities of their team members.
    • Activity Manager : Have full access to view and manage all system activities.
    • No : Can access his/her activities.
Teams Configuration :
  1. Navigate to CRM > Configuration > Sale Teams
  2. Open the specific Team Profile you want to configure
  3. Scroll to the Member tab where add the menber
Appoint Team Leader to instantly designate them as the supervisor for all added team members.
Dashboard Limit Configuration :
Set the maximum number of activities shown on the dashboard.
Navigate to Settings > Schedule Activity
Main Dashboard View: :
Contains information regarding Current, Previous, and Future activities along with assigned users' name, supervisor name, deadline date and task status.
The interface is partitioned into three distinct sections for improved workflow:
  1. Today's Activities : Activity due within the current day.
  2. Upcoming Activities : Scheduled future activity.
  3. Overdue Activities : Activity that have passed their due date.
All Activities (Menu) :
Display activity data for all system activities, including Today's, Upcoming and Overdue Activities.
Also you can see in List, Kanban, Pivot, Calender, Graph views. This menu is visible to "Activity Manager"
My Activities (Menu) :
Display activity data for the currently logged-in user's activities. This menu is visible to all users.
My Team Activities (Menu) :
Display activity data for all team members associated with the logged-in user.
This menu is visible to "Activity Manager" and "Activity Supervisor"
