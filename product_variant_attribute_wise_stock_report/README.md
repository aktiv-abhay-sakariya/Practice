# Schedule Activity
=====================


## Overview
============
The **Schedule Activity** module provides a centralized dashboard to view all scheduled tasks. From this dashboard, you can efficiently manage activities by updating their status, editing details, viewing information, or deleting entries.


## Key Features
================
1) All system activities are displayed and managed within a single, centralized dashboard. The interface is partitioned into three distinct sections for improved workflow:
    1. Today's Activities : Activity due within the current day.
    2. Upcoming Activities : Scheduled future activity.
    3. Overdue Activities : Activity that have passed their due date.

2) Activity visibility is controlled by user roles:
    1. Activity Supervisor : Can access their own activities, as well as the activities of their team members.
    2. Activity Manager :  Have full access to view and manage all system activities.
    3. Other users : Can access his/her activities.
